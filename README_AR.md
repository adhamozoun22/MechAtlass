# أكاديمية MechAtlas — المجموعة (د) والدليل النهائي

## التركيب
استبدل `admin/` بالمجلد الجديد (index.html، admin.css، admin.js، editor.js، manage.js). المجلد `academy/` وindex.html وservice-worker.js من المجموعة (أ) كما هي.

## المجموعة (د)
- تبويب «السلاسل»: إنشاء/تعديل/حذف سلسلة (الحذف للمدير فقط، والمواد لا تُحذف)، إضافة مواد وترتيبها (أعلى/أسفل) وإزالتها. الحفظ بالفروقات (تحديث الترتيب + إدراج الجديد + حذف المُزال) دون «حذف الكل ثم إدراج»، مع كشف فشل RLS الصامت.
- تبويب «المحذوفات»: المواد المؤرشفة. استعادة كمسودة (للمحرر والمدير). حذف نهائي للمدير فقط بكتابة DELETE: تُحذف الكتل وروابط السلاسل أولاً ثم المادة، ويتوقف ويُبلَّغ عند أي فشل.
- لم أبنِ واجهة لجدول content_references (لم تُعطَ أعمدته)؛ المراجع تُدار حالياً كنوع كتلة «مراجع» داخل المحرر. الوسوم/المراجعات/السجل: غير مبنية.
- لا يُحذف ملف الصورة/PDF من التخزين عند الحذف النهائي (سيبقى في الحاوية).

## ملاحظة على الدالة invite-editor (تحقّق منها فوراً)
ملف `review/invite-editor.PROPOSED.ts` الذي أعطيتك كتب في profiles العمود `full_name`. بما أن عمودك الفعلي `display_name`، يجب أن يكون السطر: `upsert({ id: invitedUserId, display_name: displayName }, ...)`. إن نُشرت النسخة كما هي فكل دعوة ستُتراجع (rollback) وتفشل. أكدتَ أنك تستخدم display_name، لكن افتح الدالة المنشورة وتحقق من هذا السطر بعينه.

## نتائج الاختبار (على Supabase وهمي داخل المتصفح الآلي)
واجهة الزوار 61/61، لوحة الإدارة 25/25، المحرر 31/31، السلاسل والمحذوفات 22/22.

## قائمة فحص على النظام الحقيقي (لم أستطع تنفيذها)
1. دعوة بريد حقيقي → الرابط يفتح /admin/ → تعيين كلمة المرور → دخول.
2. محرر: لا يرى «الفريق»، ولا يستطيع الحذف النهائي، وRLS تمنعه مما لا يجوز.
3. زائر بلا حساب: لا يرى المسودات ولا المؤرشف ولا يفتحها بالرابط.
4. رفع صورة وPDF → ظهورهما للزائر عبر الرابط الموقّع (يختبر سياسات Storage).
5. مادة بكل أنواع الكتل → فتحها كزائر → KaTeX يعمل.
6. سلسلة بثلاث مواد → ظهورها للزائر بالترتيب والتنقل التالي/السابق.
7. حذف نهائي لمادة مرتبطة بسجلات أخرى → يظهر خطأ واضح ولا يُفقد شيء.
8. الهاتف الحقيقي وWebIntoApp، وسحب الإنترنت (وضع الطيران) على الواجهة العامة.
9. بعد تفعيل Service Worker v30: تأكد أن /admin/ لا يُخزَّن (DevTools ← Application ← Cache).
